# Store Screen (Android TV)

Plays O'Reilly Auto Parts Series highlights, garage tips and ad breaks full-screen.

- Change videos, ad timing and tip source in `app/src/main/assets/config.json`
- Put your logo at `app/src/main/assets/logo.png` (about 400 px wide, PNG)
- Remote: Right = next video, Up = ad break now, Down = demo speed on/off
- Every commit to the `main` branch builds a new APK under the repo's Releases page
